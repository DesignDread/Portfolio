## 🛠️ Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* Framer Motion
* Vercel

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/DesignDread/Portfolio.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
